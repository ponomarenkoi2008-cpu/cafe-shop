# Cafe Shop API

Система автоматизации кофейни на Node.js и Express.

## Команда

## Маршруты API
- `GET /` — информация о кофейне
- `GET /api/menu` — получение актуального меню
- `POST /api/orders` — создание нового заказа
- `GET /api/stats` — статистика продаж по категориям
- `GET /health` — проверка работоспособности сервера
- `GET /version` — текущая версия API сервиса
